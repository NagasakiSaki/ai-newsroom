# 使用说明

## 启动

安装 Python 3.11+，双击根目录“一键启动.cmd”，或运行 `python launcher.py`。启动器创建 .venv、安装 requirements.lock.txt，并从 .env.example 创建 .env。页面默认 http://127.0.0.1:8088。

首次为演示模式，定时关闭，无模型或微信调用。旧端口已被另一份本应用占用时，应先停止旧实例；不同目录不共享管理员口令，不能同时把多个实例当成同一后台。

关闭页面不等于停止进程。使用 stop.cmd 或 `python launcher.py --stop`。后台运行需要电脑开机且不休眠。

## 不需要 Key 的资料采集

默认打开“资料库（无模型）”。去“来源与策略”填写主题、包含／排除关键词，添加公开网址；不需 AI 包时取消内置包。选择 RSS、列表、文章或站点地图，必要时加额外域名与 CSS 选择器。

保存后点顶部“一键采集资料（无模型）”，再搜索、阅读已保存正文或导出 JSON／CSV。写作演示模式不阻止真实采集，不需要假的 Key；“采编写稿（需模型）”是另一条可选入口。

自定义源默认每轮最多尝试八页，每条正文最多 24,000 字符。无发布日期保留为未知，不能自动写成实时新闻。SOURCE_POLL_MINUTES 控制资料轮询，页面定时计划控制可选写稿；全局暂停同时暂停受控采集。保存配置本身不抓取。

爬虫只取静态公开页面，不执行 JS、不登录或解验证码；关键词不是全网搜索。详见[采集指南](COLLECTION.md)。

## 模型配置

页面“API 与网络设置”支持 writer、prompt、review、visual：写作、策划、独立复审、兼容图文规划。策划与写作是主要文字服务；同服务可继承 URL／Key，但应填写服务支持的模型 ID。

- 使用供应商的 HTTPS Base URL，不带 /chat/completions、查询密钥或用户密码。
- 保存不自动测试。测试按钮会发一次实际请求，可能收费。
- 密钥留空保留原值；删除使用清除选项。换主机需重新填对应 Key。
- JSON 输出、字段校验、引用校验失败时可能重试并计费。
- 示例配置 REVIEW_MODE=off、POLISH_PASS=false，用于减少额外请求。polish 当前只能通过环境配置并重启切换。
- 首次切真实模式建议手动一篇，先观察用量与结果，避免立即开定时。

UI 配置优先于 .env 中对应的可管理字段；凭据保存机制见 [安全说明](../SECURITY.md)。不要把别人提供的 Key 放到不匹配的服务地址。

## 采编与控制

顶部“本次篇数”支持 1–20，留空沿用全局每轮配置；这是成功目标，不保证候选材料足够。当达到目标时本轮结束，失败候选可能被替换尝试。

手动指定线索可在撰稿页开始。默认自动模式由模型选择角度与整篇结构，兼容小编设置不是必选步骤。

暂停在请求结束后的检查点生效；继续接原进程内进度；中断保留成稿和缓存。发出的请求不能撤销计费。重启不恢复 Python 运行栈。**独立补插画任务当前有控制缺口**，不要依赖全局暂停来防止该任务执行。

token 提醒是软提醒；0 关闭提醒。业务额度的 0 通常代表不限。缺失 usage 不等于免费，图片调用单独统计；系统不根据未配置的单价虚构金额。

## 图片

优先用原报道和同事件材料中的真实图片，保留出处与原文件；图片少、下载被限流或链接失效时会显示缺图。

两个按钮用途不同：

- **重新搜集原图**：重新抓取与下载，不调用文字／生图模型，不修改正文或写微信。
- **按缺口补齐主题插画**：调用已配置的生图 API，有费用；按尚未使用的方案补缺，每次最多四张。无方案只回退一张模板图，方案耗尽后不会再自动策划。

生图配置在页面单独填写 provider、base_url、model、size、api_key。MiniMax 可选 auto／原生协议，完整地址示例 https://api.minimax.cn/v1/image_generation，模型 image-01；账号区域需匹配。其他兼容服务一般使用 /images/generations。

图片服务没有单独测试 HTTP 路由。成功图会缓存，相同失败请求有六小时冷却；更换凭据或协议可隔离旧失败记录。保存成功不等于鉴权成功。生成图片只用于概念示意，不冒充现场、原始评测或真实产品截图。

## 微信草稿

填写自己的 AppID／AppSecret，主动测试令牌接口；成功只证明令牌可获取，不证明所有素材／草稿权限可用。

40164 会在可解析时显示微信识别的出口 IP。按最新返回值更新 API IP 白名单；应用层直连无法保证不受 TUN 接管，也不能固定家用公网 IP。

批量按钮提交所有合格且未提交的当前版本；自动审定开启时新稿也可能自动入草稿。review_mode 非 off 时，自动审定要求复审无 blocker/major 且达到分数线；人工确认与自动门禁是不同路径。

已保存微信草稿用 media_id 标识。本地编辑或补图会产生新版本，不会自动修改微信旧稿。未知结果先查看记录并对账，不连续重试；公共账号错误会停止剩余批次，明确格式错误才有限修正。

本应用在桌面入口强制只建草稿，正式发表在公众号后台完成。删除本地稿不删除微信草稿，也不删除公共图片文件。

## 定时、代理与数据

定时使用北京时间，首次默认关闭。开启前确认真实模式、任务状态、费用与账号权限。全局暂停也暂停新闻轮询和定时采编。

新闻与文字／图片服务可分别使用本机 HTTP／混合代理；微信在应用层不继承代理。Windows 的“修复微信分流.cmd”会备份并修改本机 Clash 规则，只在你确实需要时手动运行。

data/ 包含数据库、凭据、令牌、图片、导出包和微信防重记录。不要清空它来修连接，不要上传到 GitHub。更换用户／机器时 DPAPI 配置可能需要重新填写；数据库运行中有 WAL，备份使用 SQLite 一致性备份或先停止服务。
