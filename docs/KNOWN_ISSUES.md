## 其他边界

- 原图会受反爬、限流、懒加载、URL 失效、DNS 与 TUN 影响。已配置的公共信源不保证长期可访问。
- 生图成功不保证每篇图数达标；当前每次最多四张，方案最多六条。无方案旧稿仅回退一张模板图。
- token 提醒是软提醒，不是费用硬封顶；0 业务限额通常代表不限。usage 缺失不是零收费。
- 热榜仅百度／头条默认启用，未验证对 AI 新闻的长期命中率或传播收益。
- 润色的程序校验不是完整语义事实对比，不能保证每句话事实不变。
- 状态名 ready_to_publish 为历史兼容，本地审定不等于微信草稿已保存或文章已正式发表。
- 取消旧传输不一定代表远端从未创建；有 media_id 或未知结果时需要对账。
- 删除本地稿不会删除微信草稿。远程微信草稿删除未实现。
- 单用户本机应用；未完成公网多用户、安卓 APK、容器生产部署或手机后台定时验证。
- 仅有公网 IP 不能解决公众号账号权限，出口 IP 也不应从旧日志写死。

历史个人运行数据、账号、稿件、图片和诊断日志不随源码发布。问题复现请使用合成材料和临时目录，不提交私人运行记录。

## 通用爬虫范围

- 静态 HTTP、RSS、未压缩 XML 站点地图；不执行 JS、不登录、解验证码或解析 PDF。
- 关键词只筛登记站点与本地资料，不自动发现全网所有来源。
- 自动列表／正文提取是启发式，复杂站点需 CSS；每条正文最多 24,000 字符。
- robots 不可读或访问被拒绝时停止来源；404/410 视为没有规则，扩展指令支持取决于标准库。
- 每源最多尝试三十页，HTML 深度最多二；订阅／站点地图内容展开仍受总页数限制。
- 无日期资料可保存导出，不绕过新闻写作时效门槛。
- 单次导出最多 5000 条；本地搜索目前遍历资料，尚无数据库全文索引。
- 来源／关键词修改不自动清理旧资料；新资料入库后点刷新查看。
- 内置 AI 包保持旧适配及新闻窗口，自定义爬虫有独立 robots 和页数预算。
