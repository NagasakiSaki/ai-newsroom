# 自定义信源与关键词

## 一个不需要模型 Key 的工作流程

1. 启动后进入“来源与策略”。主题可填“公共教育”“体育赛事”“城市文化”等；主题控制可选写作方向，真正筛选靠关键词。
2. 不需旧 AI 来源时关闭“同时启用内置 AI 新闻信源包”。这一项保留兼容，不是限定领域。
3. 添加真实公开网址，设置名称、模式、页数和深度。保存来源表单后还要点“保存信源与关键词”。
4. 点击顶部“一键采集资料（无模型）”。若全局暂停，先在控制区继续；若有旧任务排队，先处理它们。
5. 在“资料库（无模型）”中查看结果。本地搜索、阅读和导出都不调用模型，也不重抓原站。

写作演示模式只影响撰稿，不阻止采集真实公开页面。不要为了采集去买 Key，或填写不存在的模型。

## 五种入口模式

| 模式 | 填什么 | 行为 |
|---|---|---|
| auto | 文章、列表或订阅 URL | 根据响应识别 RSS／站点地图，或提取 HTML 并发现链接／RSS |
| rss | RSS / Atom URL | 读订阅里的文章链接，再抓正文 |
| html | 公告／博客列表 | 按链接选择器或内置规则取同域链接 |
| article | 单篇公开文章 | 只提取该页正文 |
| sitemap | 未压缩 XML 地图 | 展开 URL；支持有界站点地图索引 |

例如 URL 使用占位符 https://publisher.example/notices/，不要把这个示例域名当真实来源。对需要 JS 执行、登录或验证码的网站，本版本不能直接提取，不会绕过访问要求。

## 页数、深度和域名

- 默认每源最多尝试 8 页，可选 1–30。失败页也占尝试预算；robots 请求单独读取。health 同时记录 pages_attempted 和成功读取页数 pages_fetched。
- HTML 链接深度 0–2；RSS 和地图可展开内容，但始终受总页数预算约束。剩余链接未覆盖会标 truncated。
- 默认只跟随输入 URL 的主机。如果站点从 publisher.example 跳到 www.publisher.example，或订阅文章在另一域名，把确切域名加入“额外允许域名”。最多十个，不接受通配符／内网／用户密码。
- 页面大小最多约 2 MB，正文最多保存 24,000 字符；重复规范化 URL 更新本地快照。
- 自定义爬虫遵循 robots.txt。404/410 表示没有规则；拒绝、网络不可达等不会当成允许。请求间隔默认一秒，另参考站点 Crawl-delay／Request-rate；站点要求超过一分钟间隔时本轮停止该源。

URL、每次跳转和 DNS 都要过公网检查。代理／TUN 不意味着可访问本机或私网，也不会发送你的模型／微信凭据。

## 关键词

每行一个词或短语。留空收集范围内全部可提取文章：

```text
图书馆
教育
```

- any：任意包含词命中即可；all：全部包含词都要命中。
- 排除词任意命中就排除，优先于包含词。
- 来源自己的附加关键词与全局包含词同时生效；来源附加词内部为任意命中。
- 自定义文章按提取的标题＋正文匹配。内置订阅包按可用标题／订阅内容过滤，保留旧采集适配。
- 英文字母词使用词边界，避免 AI 命中 BRAIN 这类单词片段；中文按短语匹配。
- 关键词仅针对登记站点，不能用一个词自动检索整个互联网。

本地搜索框用空格分隔多个词时需全部匹配；它只查已有资料，不触发新的爬取。

## CSS 选择器

普通网页优先 article／main 区域；复杂站点可配置：

```text
列表链接：.notice-list a
正文区域：.article-body
```

这只是示例，必须按原站实际 HTML 选择器填写。选择器格式在保存时校验，不能保证不同网站都有同名区域。仅需要保存一页时用 article 模式，避免把整个栏目当正文。

## 时间与写作资格

自定义时间范围 0 表示不限；有可核对发布日期且超过范围的资料会过滤。没有日期的资料依然保存，published_at=null、date_basis=unknown；采集时间单独显示，不当成发布时间。

日期来自页面发布元数据、明确文章时间或订阅声明；不会把栏目侧栏的活动时间当文章日期。自动判断仍有局限，重要材料应核对原站。

每个自定义源默认只采集。勾选“允许用于可选 AI 写作”后，仍需要模型服务、有效日期与原有新闻时效／引用检查。它不代表该域名被自动认证为权威来源。静态无日期文档可以阅读、搜索、导出，不会因此冒充实时新闻自动撰稿。

## 保存位置、费用与限制

配置在本机 source_settings/main，资料在 stories，均属于被 Git 忽略的 data/ 数据库。不会把用户网址、关键词或正文写进公开 config/。设置带 revision 防止多页面覆盖，采集／采编未结束时拒绝修改。

手动采集入 collect 任务，支持已有暂停／继续／取消检查点，已保存条目保留。定时刷新沿用 SOURCE_POLL_MINUTES，写稿计划是另一条流程；保存配置本身不抓网页。

JSON／CSV 导出最多 5000 条，CSV 对公式前缀转义；JSON 带 truncated 提示。已保存资料不会随新关键词自动删除。原站内容和图片有自己的权限，导出或再发布前自行核对出处和使用范围。

只采集没有模型或搜索 API 费用，但仍需要正常网络，会占本地磁盘与网络流量。可选写作、生图和微信功能仍各自使用配置的服务。
